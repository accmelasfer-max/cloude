# رادار وظائف الأصفر

لوحة بحث عن وظيفة مالية/ضريبية في السعودية لمحمد الأصفر: إعلانات محقَّقة من عدة مصادر، مرتبة بالأولوية، مع السيرة المناسبة (إحدى خمس سير أصلية) ورسالة تقديم لكل وظيفة.

- `dashboard/index.html` — الصفحة (تُنشر كـ Artifact على claude.ai مع قاعدة بيانات `jobs` و`meta/sweep`).
- `data/sweep-YYYY-MM-DD.json` — نتيجة كل مسح بعد التحقق.
- `generator/base.json` — نصوص السير الخمس وجُمل الأدلة المستخدمة في رسائل التقديم.
- `generator/merge.py` — يدمج مخرجات الفاحصين (`verified/chunk*.json`) في `sweep.json`.
- `generator/seed_v2.py` / `seed_v2_lib.py` — يحوّل `sweep.json` إلى مستندات قاعدة البيانات ودفعات الكتابة.
- `generator/add_chunk.py` — يضيف دفعة محقَّقة جديدة دون تكرار (بالرابط أو المسمى+الشركة).

## دورة التحديث

1. بحث: وكلاء بالتوازي، واحد لكل مصدر (LinkedIn، Bayt، GulfTalent، Naukrigulf، Indeed/Glassdoor، مواقع مكاتب المراجعة، وكالات التوظيف وبوابات الجهات شبه الحكومية، المجمّعات، مسميات عربية).
2. تحقق: كل إعلان يُفتح ويُستخرج منه: مفتوح/مغلق، المتطلبات، الشهادة، للسعوديين فقط، المستوى، درجة التطابق وفق قاعدة ثابتة، وفقرة افتتاحية لرسالة التقديم.
3. دمج وإزالة تكرار ثم كتابة إلى قاعدة بيانات الصفحة عبر أداة ArtifactData.

درجة الأولوية في الصفحة = تطابق × 0.75 + حداثة النشر × 0.25.
